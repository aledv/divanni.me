# divanni.me

[![CI](https://github.com/aledv/divanni.me/actions/workflows/image.yml/badge.svg)](https://github.com/aledv/divanni.me/actions/workflows/image.yml) [![License: MIT](https://img.shields.io/badge/code-MIT-blue.svg)](LICENSE)

Source of my personal website, [divanni.me](https://divanni.me): a single-page CV with a
Portfolio of my public GitHub projects. Plain HTML, CSS and JavaScript served by nginx in a
small Docker image, with no build step and no framework.

## Features

- **Two-column CV** (about, experience, certifications, education, contact) that stacks on mobile.
- **Portfolio** of public GitHub repositories rendered from a static `data/repos.json`
  (stars, forks, watchers, language icons): the site never calls the GitHub API at runtime.
- **Desktop page snap**: at the end of the right column the next scroll gesture glides to the
  Portfolio, sized to exactly one screen for any number of repositories; works with mouse
  wheels, trackpads (inertia included) and the keyboard, and respects `prefers-reduced-motion`.
- Animated particle background behind the Portfolio (tsParticles, desktop only, paused off screen).
- Open Graph / Twitter cards, JSON-LD `Person`, `robots.txt` and `sitemap.xml`.
- Long-lived caching of CSS/JS with content-hash cache busting (`?v=<hash>`).

## Quick start

```bash
git clone https://github.com/aledv/divanni.me.git && cd divanni.me
python3 -m http.server 8000          # then open http://localhost:8000
```

Or the production image, locally:

```bash
./build.sh --force && docker compose up -d   # http://localhost:8102
docker compose down
```

## Project structure

```
index.html               the whole page
css/                     style.css, media.css (responsive) + vendored third-party CSS
js/main.js               Portfolio cards, page snap, smooth scroll to the Portfolio
js/particles-init.js     particle background (tsParticles, vendored in js/vendor/)
data/repos.json          Portfolio data, generated by tools/update_portfolio.py
img/, fonts/             images, language icons, icon fonts
nginx/                   nginx config and security headers used by the image
tools/                   update_portfolio.py (regenerates repos.json), bump_assets.py (?v= hashes)
tests/smoke_test.py      smoke test (standard library only)
```

## Updating the Portfolio

```bash
python3 tools/update_portfolio.py    # needs the GitHub CLI (gh) logged in
```

It keeps public, non-fork, non-archived repositories, sorted by stars. In my deployment the
same file is refreshed every night outside the image, so new repositories and stars show up
without a redeploy.

## Development

```bash
npm ci                                             # once: htmlhint, stylelint, ESLint (pinned)
./lint.sh                                          # all linters, non-zero exit if any fails
python3 tools/bump_assets.py                       # after editing css/*.css or js/*.js
python3 tests/smoke_test.py                        # serves the repo locally and checks it
python3 tests/smoke_test.py --url https://example.org/   # or checks a deployed site
```

`lint.sh` also needs `uv` (ruff, yamllint) and Docker (hadolint, ShellCheck).

| Language | Linter | Config |
|---|---|---|
| HTML | htmlhint | defaults |
| CSS | stylelint | `stylelint.config.mjs` |
| JavaScript | ESLint | `eslint.config.mjs` (vendored `js/vendor/` excluded) |
| Python | ruff check + format | `ruff.toml` |
| YAML | yamllint `--strict` | `.yamllint.yml` |
| Dockerfile | hadolint | defaults |
| Shell | ShellCheck | defaults |

The smoke test checks that the pages answer 200, every local asset referenced by `index.html`
and the CSS exists, anchors resolve, the HTML is well formed, the `?v=` hashes are current and
`sitemap.xml` / JSON-LD are valid.

CI (`.github/workflows/image.yml`) runs the linters, then the smoke test, then builds a
multi-arch image (`linux/arm64`, `linux/amd64`) and pushes it to `ghcr.io/aledv/divanni-me`.
